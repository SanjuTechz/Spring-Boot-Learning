# REST API Architecture

REST is an architectural style for networked applications. In a typical Spring REST API, HTTP requests are mapped to controller methods, application operations are handled by services, and persisted data is accessed through repositories.

## Common HTTP methods

| Method | Typical use |
|---|---|
| GET | Retrieve a resource or collection |
| POST | Create a resource or submit an operation |
| PUT | Replace a resource representation |
| PATCH | Partially update a resource |
| DELETE | Delete a resource |

Related: [[service-layer-pattern]], [[repository-pattern]].
