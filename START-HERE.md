# Start Here

## Your learning loop

1. **Study:** Read one focused lesson (about 20 minutes).
2. **Build:** Complete the coding task before looking at a worked solution.
3. **Explain:** Write the concept in your own words in Obsidian.
4. **Verify:** Run the application and test the endpoint or behavior.
5. **Reflect:** Record mistakes and what you would do differently.
6. **Commit:** Save the working result with a clear Git commit.

## Ground rules

- Prefer official Spring documentation for framework behavior.
- Do not copy AI-generated code without understanding it.
- Keep challenges, your implementation, and reference solutions clearly separated.
- Mark a topic complete only when you can explain and implement it without step-by-step help.
