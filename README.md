# Spring Boot Learning

A practical learning workspace for Java 21, Spring Boot 4, REST APIs, and the **My Daylist API** project.

This repository is also designed to work as an Obsidian vault: open this folder as a vault, then use the Markdown notes and `[[wikilinks]]` to connect concepts.

## How to use this repository

1. Open this folder in Obsidian as a vault.
2. Read `START-HERE.md` and `notes/roadmap.md`.
3. For each daily challenge, read the matching note in `notes/daily-exercises/`.
4. Implement the exercise in `exercises/` or the main project in `projects/my-daylist-api/`.
5. Record explanations, mistakes, and useful links in Obsidian.
6. Commit working changes to Git with a meaningful message.

## Recommended tools

- Java 24
- Spring Boot 4.x
- Maven (use the Maven Wrapper generated by Spring Initializr)
- VS Code or another Java IDE
- Obsidian
- Git
- Postman for HTTP testing

## Important

Do not commit passwords, API keys, tokens, private data, or real production configuration. Keep secrets in environment variables or ignored local configuration files.
